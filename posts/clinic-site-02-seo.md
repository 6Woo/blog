앞 글에서 병원 이름 도메인으로 사이트를 옮겼어요. 하지만 페이지가 있다고 검색에 나오는 건 아니에요. 검색 엔진에 "여기 이런 페이지가 있어요"라고 알려야 해요. 2026년 7월 3일에 한 작업이에요.

## 문제: 사이트가 있어도 검색 엔진이 모르면 없는 것과 같아요

주소를 옮긴 직후에는 검색 엔진이 새 주소를 몰라요. 이름이 같아도 어느 주소가 진짜인지 알려 주지 않으면 옛 주소와 새 주소가 따로 평가될 수 있어요.

## 해결: 검색 엔진이 읽는 표지판을 6가지 달았어요

- robots.txt: 어디를 읽어도 되는지 알려 줘요.
- sitemap.xml: 페이지 목록이에요.
- canonical: 이 페이지의 대표 주소가 어디인지 적어요. 옛 주소와 겹치는 문제를 막아요.
- og 태그와 og:image: 링크를 공유할 때 보이는 제목과 대표 사진이에요.
- JSON-LD(MedicalClinic): 이 페이지가 병원이라는 것을 기계가 읽는 형식으로 적어 둔 거예요.
- 사이트 설명 문구: ==네이버 설명 제한이 80자라서 51자로 맞췄어요.==

## 네이버 등록: 소유 확인과 지도 정보 연결

1. 네이버 서치어드바이저에 사이트를 등록하고 내 사이트가 맞다는 소유 확인을 통과했어요. 페이지 head에 메타 태그를 넣는 방식이에요.
2. robots.txt가 정상으로 수집되는 것도 확인했어요.
3. 간단 체크 도구에 경고 표시가 남았는데, 서버 응답은 정상(200)이어서 도구가 예전 결과를 들고 있는 것으로 봤어요. 도구의 오래된 기억을 서버 문제로 오해하면 헛수고라서, 서버 응답부터 직접 열어 봤어요.
4. 네이버 지도의 병원 정보(스마트플레이스)는 병원 쪽 인증을 거친 뒤 기본 정보에 홈페이지 주소로 새 도메인을 등록했어요.

## 결과와 아직 모르는 것

| 항목 | 상태 |
|---|---|
| 소유 확인 | 통과 |
| robots.txt 수집 | 정상 확인 |
| 지도 정보에 홈페이지 주소 | 등록 완료 |
| 검색 노출 순위, 방문자 수 | 미확인 |

등록이 끝났다는 것과 검색 첫 화면에 나온다는 것은 다른 말이에요. 노출은 며칠 뒤 다시 확인해서 적을게요. 숫자가 나오면 이 폴더에 이어서 쓸게요.

## 정리

1. 사이트를 만드는 것과 검색에 알리는 것은 별개의 일이에요.
2. 글자 수 제한(네이버 80자)은 미리 맞췄어요. 설명 문구는 51자예요.
3. 도구에 경고가 떠도 서버 응답을 직접 열어 보고 판단해요 ㅎㅎ
