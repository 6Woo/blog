## 배경: 상단바에서 CPU, 메모리, 디스크, 네트워크를 보고 싶었어요

기존 앱은 상단바 자리를 많이 차지하거나 필요 없는 기능이 많았어요. 그래서 그누가 필요한 것만 담은 MenuStats를 직접 만들었어요.

항목마다 작은 라벨 아래에 값을 두 줄로 쌓고, 옆에 최근 변화를 작은 막대로 보여줘요. 항목마다 상단바 표시를 켜고 끌 수 있어서 노치에 가려지는 항목을 뺄 수 있어요.

![MenuStats 실제 화면: 밝은 상단바, 어두운 상단바, 펼친 메뉴](img/menustats.png)

위 그림은 앱이 스스로 그려 낸 실제 화면이에요. 위 두 줄이 밝은 배경과 어두운 배경의 상단바이고, 아래가 펼친 메뉴예요. ㅎㅎ

지금 쓰는 메뉴는 이렇게 생겼어요. CPU 코어별 막대, 메모리 구성, 디스크와 네트워크 속도가 한 화면에 나와요. 메뉴 아래쪽에서 상단바를 "아이콘 하나"나 "숫자와 그래프"로 고르고, 자세히 보기에 넣을 항목(CPU, 메모리, 디스크, 네트워크)을 체크하고, 로그인 시 자동 실행을 켜요.

![MenuStats 펼친 메뉴: CPU 19%, 메모리 48.0GB 중 36.9GB 사용, 디스크와 네트워크 속도, 상단바 설정 항목](img/menustats-menu.png)

이 화면에서 읽을 수 있는 것은 이래요. CPU는 Super 6코어와 Performance 12코어가 따로 막대로 나와요. 메모리는 48.0GB 중 36.9GB를 쓰고, 항목별로 python3.12 5.2GB, 버전 번호(2.1.330, 2.1.331)로 나오는 프로그램 두 개 3.7GB와 1.0GB, OrbStack 0.5GB, Google Chrome 0.4GB, 기타 시스템 2.7GB, 고정(커널) 4.6GB, 압축 18.8GB, 여유와 캐시 11.1GB예요. 앱이 직접 쥔 메모리는 합쳐서 14GB쯤인데 압축이 18.8GB로 가장 커요. 메모리가 빠듯해 보여도 상당 부분이 압축으로 버티는 상태라는 걸 이 그림 한 장으로 알았어요. 디스크는 읽기 100.1MB/s에 남은 공간 39.0GB이고, 네트워크는 2.7MB/s예요.

측정 값은 다른 도구와 대조해 검증했어요. 메모리는 활성 상태 보기의 "사용 중" 정의로 계산해서 `top` 보다 작게 나오는 게 정상이에요. 이 메뉴의 메모리 숫자는 고정(커널)과 압축을 포함한 값이에요. 네트워크는 32비트 카운터가 4GB에서 한 바퀴 돌아서 64비트 카운터를 읽고, VPN 같은 가상 인터페이스는 이중 집계되지 않게 뺐어요.

## 문제: CPU가 77도인데 팬은 최저 2,317rpm

게임을 돌리면 CPU가 77도까지 올랐는데 팬은 최저 속도인 2,317rpm에 머물렀어요. 이 맥의 팬 범위는 2,317에서 6,800rpm이에요.

## 원인: 애플 기본 정책이 정숙에 치우쳐 있음

실측해 보니 기본 정책은 온도가 꽤 올라도 팬을 최저에 두는 쪽이에요. 팬은 애플 자동 상태에서 0rpm까지도 내려가요.

## 해결: 온도에 비례해 올리는 곡선 데몬

![팬 곡선](img/fan.png)

- 50도 이하는 애플 자동에 맡겨요.
- 50도에서 80도 사이는 2,317에서 6,800rpm으로 선형으로 올려요.
- 80도 이상은 최대로 돌려요.
- 올릴 땐 바로 올리고, 3도 이상 내려가면 한 번에 1도씩 천천히 내려요. 팬 소리가 오르내리지 않게 하려는 거예요.

안전장치도 같이 넣었어요. 데몬이 종료되면 항상 애플 자동으로 복귀하고, 시작할 때도 먼저 자동으로 돌려요.

센서가 110도 이상이거나 값이 없으면 자동으로 돌아가요. (•̀ᴗ•́)و

## 결과: 77도에서 2,317rpm이 약 6,350rpm으로

| 항목 | 값 |
|---|---|
| 77도에서 팬, 기존 | 2,317rpm |
| 77도에서 팬, 곡선 적용(계산) | 약 6,350rpm |
| 최대 전환 실측 | 4초 안에 2,323에서 6,619rpm |
| 자동 복귀 실측 | 5초 안에 5,377에서 2,333rpm |

## 함정: 화면이 꺼지면 온도 센서가 0에서 8도를 줘요

코어가 전원 차단 상태가 되면 같은 센서가 0에서 8도 같은 값을 보고해요. 같은 순간 다른 센서는 41도였어요. 20도 미만은 버리고, 전부 버려지면 GPU 쪽 센서의 최댓값으로 대신해요.

## 정리

1. 기본 정책을 의심하려면 먼저 실측해요. 77도에서 2,317rpm이라는 숫자가 출발점이었어요.
2. 하드웨어를 건드릴 땐 복귀 경로를 먼저 만들어요.
3. 센서 값은 항상 정상이 아니에요. 범위를 검사해서 버릴 값을 정해 둬요.
